# Diretrizes do portfólio (Maria Eduarda Barzagli)

Regra principal: não é um novo portfólio, é uma versão melhor do que já existe. Evoluir, não reinventar.

- Preservar o design system atual: paleta, tipografia e escala, espaçamentos, radius, sombras, cards, botões, ícones, grid. Sem novas cores, sem gradientes, sem glassmorphism, sem estilo visual próprio para seções de IA.
- Manter a estrutura atual; ajustes incrementais. Não remover seções existentes. Reutilizar/adaptar componentes antes de criar novos; evitar duplicação de cards/botões/badges.
- Mobile first: leitura rápida, CTAs tocáveis (≥44px), cards empilhados, sem overflow horizontal, sem tabelas quebradas, textos com largura confortável. Desktop aproveita espaço sem alargar demais os textos.
- Sem gambiarra responsiva: evitar absolutes desnecessários, tamanhos fixos que quebram, esconder conteúdo para caber.
- Usar componentes shadcn/ui (via DesignSystemDefault) sempre que houver equivalente, estilizados com o design system — sem cara de template/dashboard.
- Hierarquia > decoração. Se resolve com título + texto + 3 cards, não adicionar mais.
- Animações discretas e funcionais (hover, entrada suave, expansão). Sem parallax exagerado, flutuação, typing, partículas, "AI magic".
- Acessibilidade: contraste, foco visível, teclado, labels/aria, alt text, áreas de toque.
- Performance: imagens otimizadas, lazy loading, sem libs para animações pequenas.
- Antes de mexer: "consigo resolver reutilizando a estrutura e o design system existentes?" Se sim, reutilizar; se não, o menor componente novo possível.

Evolução por seção: Hero (manter; "Product Manager Pleno", posicionamento, localização + remoto) · Sobre (personalidade e contexto) · Impacto (reforçar métricas) · Cases (aprofundar narrativa e papel) · IA (IA no meu trabalho, Agentes, Skills, IA nos produtos) · Stack (grupos empilhados no mobile) · Trajetória (manter) · Eventos (manter; fotos depois) · Contato (melhorar CTA).

Critério de sucesso: posicionamento PM Pleno claro; recrutador entende o perfil rápido; cases mostram autonomia e decisão; IA/agentes/Skills como diferencial concreto; discovery, dados, estratégia e impacto evidentes; personalidade sem perder profissionalismo; design system reconhecível; mobile excelente.
